# Home V2 · 0.9.13

Home păstrează stilul navy, mint, cream și logo-ul chunky. Ordinea vizuală este logo → personaj și van 3D → PLAY → Upgrades / Collection / Cosmetics → Next Target. Portretul live are o lumină discretă în fundal, personajul este în fața vanului, iar frigiderul rămâne ca indiciu de loot. Apariția cosmetică se actualizează în același preview ca înainte.

Next Target folosește progresul real: primul tutorial, runda de alarmă, obiectul semnătură, upgrade-ul Strength sau Van, Rush Hour, Final Job ori următorul obiectiv de campanie. Butonul său deschide ecranul util și focalizează cardul relevant din Upgrades; când Final Job este pregătit, îl pornește direct.

Stats se deschide din Settings prin „Profile & Stats”. Comenzile DEV sunt într-un sertar închis la baza Settings și nu sunt create când development mode este oprit. PLAY continuă traseul existent al tutorialului și al Jobs. Progresia, economia și modul de salvare nu s-au schimbat.
